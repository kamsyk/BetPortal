# BpDbLayer

Data access layer for the BetPortal application, built with Entity Framework Core targeting .NET 9.

## Overview

BpDbLayer provides the database context, entity models, and data access infrastructure for the BetPortal betting platform. It uses SQL Server as the database provider and follows the repository pattern for data access.

## How to Generate DB Migrations and Update the Database
To create and apply database migrations using Entity Framework Core, see the Utils/MigrationsDevelop.bat script. This script automates the process of generating migrations and updating the database schema.
